# Du Barbearia

Prévia responsiva em HTML, CSS e JavaScript, com as imagens fornecidas pela barbearia.

Site estático: não requer instalação nem etapa de build. Abra `index.html` ou sirva a pasta com um servidor HTTP local.

## Vercel

Importe este repositório com o preset Other, sem comando de build, e diretório de saída `.`.
